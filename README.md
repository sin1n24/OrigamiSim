# OrigamiSim

折り紙を実際に折るように遊ぶ、ガイド付きの3D折り紙シミュレーターです。Three.js / TypeScript で実装しています。

> **⚠️ 現在制作途中のプロジェクトです。** 仕様や見た目は今後も変わる可能性があります。

## 遊び方

正方形の紙を、実在の折り図に基づいた手順でステップごとにクリックして折っていきます。次に折る場所は赤い線でガイドされます。全ステップを折り終えると完成演出とともに、平らだった紙が実際の立体形状に開きます。

現在収録しているモデル:

- 紙コップ
- きつねの顔
- ヨット
- 紙飛行機
- 山

いずれも、実際の折り紙の折り図・写真を参照して手順を再現しています(独自に創作した折り方は使っていません)。
